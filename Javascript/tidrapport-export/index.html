Tidrapport-export

Fristående, skrivskyddad vy av ics2tidrapport.py-flödet. Kalenderlänken hämtas från en hemlighet (Script Property KALENDER_TIDRAPPORT_URL) på en egen, Bokio-fri Apps Script-backend — den skickas aldrig från sidan. Denna backend innehåller ingen Bokio-kod alls, så den kan inte skapa fakturor eller anropa Bokio.

API

Deploya Javascript/gscript-tidrapport/Code.gs som egen Web App och sätt Script Property KALENDER_TIDRAPPORT_URL. Klistra sedan in din /exec-URL här.
